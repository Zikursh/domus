# Oscar's Domus

A 3D model of a Roman domus built in Blender for 6th grade Latin, viewable in any browser.

The whole site is `index.html`. The model is embedded in the page, so there are no other files to upload.

## Hosting on GitHub Pages

1. Create a public repository and upload `index.html` and this `README.md`.
2. Settings, then Pages. Under Build and deployment choose Deploy from a branch, branch `main`, folder `/ (root)`. Save.
3. After about a minute the site is live at `https://<username>.github.io/<repository>/`.

## Using the viewer

- Drag to orbit, scroll or pinch to zoom, right-drag or two fingers to pan.
- Press a stop (I to VI) to fly to that room and look down into it over the walls.
- Walls off / Walls on hides or shows the walls so every room is visible at once. Plan view looks straight down. Whole house returns to the opening view.
